# H1 – Caso real: Control de inventario de rollos de tela

## Descripción del problema

El caso corresponde a una tienda dedicada a la venta de tapices y telas para tapicería, donde el control de inventario se realiza mediante hojas de cálculo de Microsoft Excel.

Cada rollo de tela cuenta con un identificador único y se registra individualmente para controlar sus características y disponibilidad. La información almacenada incluye el ID del rollo, SKU, tejido, color, lote, ancho, metros iniciales, metros cortados, merma, stock actual y ubicación.

El proceso requiere consultar los registros para localizar rollos, verificar la cantidad de metros disponibles y actualizar las existencias cuando se realizan cortes o se detectan materiales defectuosos.

También se debe identificar cuándo un rollo tiene menos de 2,5 metros disponibles, ya que debe trasladarse a la zona de retazos.

El proceso involucra principalmente al personal encargado de las ventas y del almacén, quienes necesitan consultar y mantener actualizada la información del inventario.

Se estima que el inventario puede contener 200 rollos o más, aunque no se dispone de una cantidad exacta. Durante la experiencia laboral, algunas búsquedas de información podían tardar aproximadamente entre 5 y 10 minutos.

## Objetivo

Analizar y optimizar las operaciones de búsqueda y consulta de existencias de rollos de tela, utilizando estructuras de datos y mediciones de rendimiento.

## Datos de prueba

Se utilizarán 20 registros , elaborados siguiendo las características y reglas de funcionamiento del inventario
