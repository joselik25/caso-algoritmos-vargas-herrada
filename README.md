# Expediente - Análisis de Algoritmos

**Estudiante:** Jhonmar Vargas Herrada

**Proyecto:** Análisis de algoritmos aplicado al inventario de una tienda de tapices.

## Descripción del proyecto

Este expediente presenta el análisis de los procesos de inventario de una tienda de tapices. Se estudian estructuras de datos, algoritmos de búsqueda, ordenamiento y optimización mediante ejercicios y mediciones experimentales.

Los datos utilizados en las pruebas son sintéticos y tienen fines académicos. El problema de optimización de H3 es un ejercicio análogo al negocio y no representa el procedimiento habitual de atención de pedidos.
